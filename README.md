# AgentVerse Hub

一个面向中文用户的 AI 能力发现站，集中整理热门 Skills、提示词、MCP、CLI、智能体和自动化工作流。

在线访问：<https://fuzzylogic112.github.io/agentverse-hub/>

## 功能

- 六大资源模块，支持关键词、行业、功能与类型组合筛选
- 按行业、功能、资源类型自动滚动的动态能力雷达
- 三套可切换的工作流组合示例
- 趋势榜、详情弹窗、安装命令复制与本地收藏
- `Ctrl/Cmd + K` 快捷搜索、深色模式和响应式移动端布局
- 零构建静态站点，可直接部署到 GitHub Pages

## 本地预览

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 内容维护

资源数据位于 `app.js` 顶部的 `resources` 数组。每条资源包含类型、行业、功能、标签、热度、官方链接和可选安装命令。新增数据后，筛选、快捷搜索、滚动雷达数量和详情弹窗会自动更新。
